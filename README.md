# Cantonment: Dhaka Streets

An open world browser game set on the real map of **Dhaka Cantonment** and its surroundings (Kachukhet, Mirpur 14, Banani, Mohakhali, Matikata, Manikdi, ECB Chattar, Nirjhor). Everything runs in the browser with no install and no image or audio assets: the city, vehicles, characters, weapons, textures and sounds are all generated by code.

## Play

Open `index.html` in Chrome or Edge (double click works, no server needed). Click the game once to capture the mouse.

| Key | Action |
| --- | --- |
| W A S D, mouse | Move / drive, look |
| Shift, Space | Sprint, jump (handbrake in vehicles) |
| F | Enter or exit a vehicle |
| E | Interact: doors, shops, bus stops, hire a CNG / taxi / rickshaw |
| Left / right mouse, R | Shoot or punch, aim, reload |
| Tab (hold), 1 to 9, scroll | Weapon wheel, quick select |
| M | Full map: drag, zoom, click to set a GPS waypoint |
| H, L, Q, V | Horn (first aid on foot), headlights, siren, camera |
| J | Start a job (taxi / CNG passengers, bus route, bike food delivery) |
| F5, Esc | Quick save, pause (settings, weather and time controls) |

## What is in it

- **Real location.** 35,700 building footprints, 2,275 roads (Airport Road, Kurmitola Road, Mirpur Banani flyover, Dhaka Elevated Expressway), lakes, parks, the golf course, rail line, 60 real bus stops and the cantonment gates, converted from OpenStreetMap. The map is 3.5 km by 6.6 km at 1:1 scale.
- **3,300+ doors you can walk through**: restaurants, tea stalls, general stores, pharmacies, hospitals, banks, mosques, schools, hotels, police stations, salons, clothing stores, gun shops, car showrooms and ordinary residences, each with its own interior.
- **Character customisation**: body, skin, height, build, hair, beard, tops (T-shirt, panjabi, suit, kameez, sari and more), bottoms (jeans, lungi), shoes, headwear, eyewear. Change again at home, clothing stores and salons.
- **Vehicles**: sedans, hatchback, SUV, sports car, pickup, microbus, city bus, cargo truck, CNG auto-rickshaw, cycle rickshaw, motorbikes, army jeep, police patrol, ambulance. Left hand traffic, traffic signals, parked cars, damage, fire and explosions.
- **Weapons**: cricket bat, 9mm pistol, revolver, micro SMG, AK rifle, service carbine, pump shotgun, sniper rifle, LMG, RPG, grenades, body armour.
- **Buses and rides**: three bus lines stop at the real stops. Board as a passenger, drive one as a job, or hire a CNG, taxi or rickshaw to your waypoint.
- **Weather and time**: 24 hour day and night cycle with clear, cloudy, overcast, drizzle, monsoon rain, Kalboishakhi storm with lightning, winter fog and dusty haze. Wet roads get slippery and reflective.
- **Wanted system**: police outside, Military Police inside the cantonment, special forces at higher levels.
- **Missions, jobs, properties, garage, bank, save game.**
- **Sound**: engines, horns, gunfire, rain, thunder, sirens, footsteps and ambience, all synthesised with WebAudio.
- **Boys Club**: a password locked roster of extra playable characters with their own houses and cars.

## Graphics

Three.js with physically based materials, soft shadows, a procedural sky with volumetric looking clouds, image based reflections, HDR bloom, ACES tone mapping and wet surface shading. Use **Esc > Settings > Graphics quality** if it runs slowly.

## Project layout

```
index.html        page, HUD and menus
data/map.js       baked game map (generated)
js/               game code (world, vehicles, characters, weapons, AI, UI, audio)
vendor/           three.js r147 and post processing passes
tools/            map builder (OpenStreetMap to data/map.js) and test scripts
```

To rebuild the map: `cd tools && node fetch.mjs && node build-map.mjs`.
